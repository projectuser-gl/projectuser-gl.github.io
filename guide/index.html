1 · Getting started in three steps

  1. Unzip the downloadRight-click the ZIP and choose Extract All (Windows) or double-click it (Mac). Keep the files together in one folder.
  2. Double-click the HTML fileIt opens in your web browser and runs from your own computer. Nothing installs, no account is created, and no internet connection is needed.
  3. Choose where to saveOn the first screen, pick a folder. From then on every change you make is written straight into a real file you can see, copy and back up.

That is the whole setup. Everything below is detail for when you need it.

3 · Opening it

Windows

Double-click the .html file. If Windows asks which program to use, choose Google Chrome or Microsoft Edge. You can also double-click Start on Windows.bat.

Mac

Double-click the .html file. To use Chrome or Edge instead of Safari — worth doing, see section 6 — right-click the file, choose Open With, and pick the browser you want.

A macOS security warning on the .command file?
macOS blocks files downloaded from the internet the first time. You can ignore the warning entirely and open the .html file directly — it does exactly the same thing.

5 · Where your work is kept

This matters more than anything else on this page, so it is worth thirty seconds.

Until you connect a folder, the app keeps your work in the browser's own storage on that computer. That is fine and it survives closing the browser and restarting the machine — but it lives in one place only, and it is the same storage that gets wiped when someone clears browsing data.

The one real risk
Clearing your browser's cookies and site data deletes the app's data along with it. No program can prevent that. Connecting a folder is what makes it a non-issue — after that your work is a normal file on your disk.

6 · Connect a folder (do this once)

Open Backup & Sync in the app and choose Connect a folder. Pick any folder you like — Documents, an external drive, a USB stick, or a cloud folder. From that moment on, every change you make is written into that folder within about a second. You do not press save, and you do not have to remember anything.

It does not have to be a cloud folder. A plain folder on your own disk is a complete backup for one computer. Cloud only matters if you want two computers.

7 · Using it on two computers

There is no server and no account, so two computers are joined by a folder they can both see — that is, a folder inside Dropbox, OneDrive, Google Drive or iCloud Drive.

Laptopconnects to the folder
→
Shared folderDropbox · Drive · OneDrive · iCloud
→
Desktopconnects to the same folder
  1. On the first computerOpen Backup & Sync, choose Connect a folder, and pick a folder inside your cloud drive — for example Dropbox/MyBusiness. Let it finish syncing.
  2. On the second computerCopy the same .html file across (or download it again), open it, and choose I've used this before — find my work. Point it at the very same folder. Your work appears.
  3. From then onBoth computers write into that folder and both read from it. Close the app on one, open it on the other, and your work is there.

What happens if you edit in both places

The app merges rather than overwrites. Each record carries the time it was last changed, and when a newer version of the file arrives the newer record wins, record by record. Editing different things on the two computers is safe. Editing the same record on both while they are offline means the later edit wins.

Give the cloud a moment
Dropbox and Drive need a few seconds to move the file. If you close the laptop lid the instant you finish typing and immediately open the desktop, the file may not have arrived yet. Wait until your cloud app shows it has finished syncing.
Do not put the folder in two different cloud services
One folder, one cloud service. Two services watching the same folder will fight over it and can leave conflicted copies.

8 · If you use Safari or Firefox

Everything works except automatic folder saving. You keep your work safe by saving a backup file by hand instead — it is one click, and doing it once a week or two is plenty for most people.

  1. Open Backup & SyncThe screen tells you which browser you are on and what applies to you.
  2. Click Save a backupA .json file lands in your Downloads folder with the date in its name.
  3. Keep it somewhere sensibleMove it into Dropbox, Drive or an external disk. That file is your entire business and it can be restored on any computer.

If you would rather have the automatic version: right-click the .html file, choose Open With, and pick Chrome or Edge. Same file, same data, nothing to set up again. Both are free, and your data still never leaves your computer.

9 · Everyday use

Adding and changing records

The blue button at the top right adds a new record. Click any row in a table to open and edit it. Required fields are marked with an asterisk; the app tells you if one is missing rather than losing what you typed.

The board

Drag a card from one column to another to change its status — booked to done, done to paid. It is the fastest way to keep a week tidy.

Invoices

Completed work waits on the invoices screen until you raise an invoice for it. Invoices print cleanly in black and white, whatever colour theme you are using, and your browser's print dialog can save them as PDF.

Reports

Any date range you like. Profit and loss, work by customer, by worker and by category. Print them, save them as PDF, or export any table to CSV for a spreadsheet or an accountant.

Settings

Your business name and address go on invoices. There are sixteen currencies, a date format, and a colour theme. Numbers and targets specific to your trade live here too.

10 · Backups and moving to a new computer

A backup file, any time

Backup & Sync → Save a backup writes one .json file containing everything. Keep a copy somewhere other than the computer it came from.

Restoring

Backup & Sync → Restore, choose the file, confirm. It replaces what is on that computer, so it tells you how many records the backup contains before it does anything.

New computer

  1. Take the app with youCopy the .html file across, or download it again from your Etsy purchases. It is the same file.
  2. Bring the work acrossEither connect to the same folder, or restore your latest backup file.
  3. Check the totalThe Backup & Sync screen shows how many records you have. If it matches what you expect, you are done.

12 · Frequently asked

Does it need the internet?

No. Once downloaded it runs with the network off. Nothing is sent anywhere, ever.

Is there an account or a subscription?

Neither. You bought the file; it is yours, and it keeps working.

Can I install it on more than one of my own computers?

Yes. Use it on as many of your own machines as you like.

Where exactly is my data?

In your browser's storage on your computer, and — once you connect a folder — in a plain file in that folder. Nowhere else. There is no server involved at any point.

Can I use it on a phone or tablet?

The screens work on a tablet. A phone is cramped for data entry and cannot connect a folder, so treat it as a viewer rather than the main machine.

Will there be updates?

Yes, free for your version. Updating is downloading the newer file and opening it — your data is not inside the app file, so it carries over.

Something is still wrong.

Message me through Etsy. Tell me which browser and which screen, and I will sort it out.
